# Proyecto 2 — Diorama con Raytracing

Proyecto de **Gráficas por Computadora** desarrollado en Rust.

La implementación utiliza el mismo stack de los laboratorios del curso:

- `minifb` para la ventana y el render loop.
- `nalgebra-glm` para vectores y operaciones matemáticas.
- Un framebuffer y un ray tracer implementados dentro del proyecto.

## Estado

En desarrollo. El primer módulo prepara la ventana, el framebuffer y la base
del renderizador en tiempo real.

## Ejecutar

```bash
cargo run
```
